### 🚀 Otimizações para Netlify

**1. Sistema de Build Customizado**

* Script especializado: `build-simple.js` que usa `execSync` ao invés de imports ESM.
* Dependências explícitas: instala todas as dependências de build diretamente.
* Bundle otimizado: serverless functions com **esbuild** e external modules.

**2. Configuração Netlify Completa**

```toml
# netlify.toml otimizado
[build]
  publish = "dist/public"
  command = "bash netlify-build.sh"
  functions = "netlify/functions"

[build.environment]
  NODE_VERSION = "20"
  NPM_FLAGS = "--legacy-peer-deps"
```

**3. Headers de Segurança e CORS**

```txt
# _headers otimizado para iframe
/*
  X-Frame-Options: ALLOWALL
  Content-Security-Policy: frame-ancestors *; script-src 'self' 'unsafe-inline' 'unsafe-eval' https://replit.com
  Access-Control-Allow-Origin: *
```

**4. Redirects SPA Otimizados**

```txt
# _redirects

```

**5. Funções Serverless Otimizadas**

* External modules: database drivers externos para reduzir bundle size.
* ESM exports: formato correto `export { handler }` para Netlify.
* Multiple functions: `api.js` (3.9MB) + `test-api.js` (1.3KB).

**6. Cache e Performance**

```toml
# Cache otimizado por tipo de arquivo
[[headers]]
  for = "/*.js"
  [headers.values]
    Cache-Control = "public, max-age=31536000, immutable"
```

**7. Correções de Segurança**

* CSP unificado: removido meta tag CSP conflitante do HTML.
* Secrets limpos: credenciais removidas de arquivos de documentação.
* Headers consolidados: CORS e iframe headers centralizados.

**8. Build Multi-Stage**

```bash
# netlify-build.sh
npm install --no-save vite esbuild...  # Dependências explícitas
npx vite build                         # Frontend build
npx esbuild netlify/functions/api.ts   # Serverless build
```

**9. Fallbacks e Error Handling**

* API Retry: sistema robusto em `api-retry.ts`.
* Iframe detection: auto-detecção de ambiente iframe.
* CORS fallbacks: múltiplas estratégias para diferentes origens.
