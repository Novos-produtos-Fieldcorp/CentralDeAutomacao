[29/08/2025, 11:22:06] Gabriel Mauro: Para puxar as tags (labels) de um usuário (contato) no Chatwoot via API, deve-se usar o endpoint de contatos rotulados (contact labels):

O endpoint para adicionar ou obter as tags de um contato é:

text
/api/v1/accounts/{account_id}/contacts/{id}/labels 
É possível fazer uma requisição POST para adicionar labels, enviando um array com os nomes das tags.

Para puxar as tags existentes de um usuário, usa-se uma requisição GET nesse endpoint, especificando o account_id e o id do contato.

A resposta inclui os labels associados ao contato (usuário).

Exemplo para adicionar tags via curl:

text
curl --request POST \
--url https://app.chatwoot.com/api/v1/accounts/{account_id}/contacts/{id}/labels \
--header 'Content-Type: application/json' \
--header 'api_access_token: <api-key>' \
--data '{
"labels": [
"support",
"billing"
]}'
Também é possível adicionar tags como atributos customizados diretamente no contato para mantê-las fixas no usuário, não apenas na conversa.

Além disso, para puxar dados do usuário, o endpoint para obter detalhes é:

text
GET /platform/api/v1/users/{id}
que retorna dados do usuário, mas as tags específicas ficam nos contatos via o endpoint de labels.

Em resumo, para puxar as tags do usuário, usar o endpoint de labels do contato dentro da conta na API do Chatwoot.
