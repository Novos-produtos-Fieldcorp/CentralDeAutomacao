Central de Automação ->
Plataforma web para gestão operacional de motoristas, agregados e clientes.
Indicada para empresas de transporte, logística ou gestão de frotas.

Funcionalidades ->
	•	Cadastro, edição e exclusão de motoristas e agregados
	•	Envio e visualização de documentos dos motoristas
	•	Filtros por cidade, status, tipo de veículo, cliente, função, entre outros
	•	Comunicação em massa com motoristas (chat e mensagens)
	•	Controle de compliance (LGPD)
	•	Painéis de controle e tabelas dinâmicas
	•	Ações em massa para facilitar a gestão

Tecnologias utilizadas ->
	•	Frontend: React, Vite, TypeScript, TailwindCSS
	•	Backend e banco de dados: Supabase
	•	Outros: React Hot Toast, Lucide React, ESLint, PostCSS
